# Reference voices

`hindi_male_fleurs.wav` is an 8-second clip derived from
[`google/fleurs`](https://huggingface.co/datasets/google/fleurs), config
`hi_in`, validation row 2. FLEURS is released under CC-BY-4.0.

It is included only as a neutral Hindi male timbre reference for local,
non-impersonating TTS experiments. Replace it with your own recording (or a
voice you have written permission to clone) before publishing a track. Do not
use it to imitate a real person or a known singer.
